% A small born-digital TeX document, used by the tutorial in README.md.
%
% Build it with:
%     pdflatex -output-directory=examples examples/sample.tex
%
% Three displayed equations, which the detector finds; one inline formula, which
% `--inline` finds; and one bold vector, which nothing can find, because \mathbf and
% bold prose are the same font.  The last is what the tutorial uses to show --bbox.
\documentclass[11pt]{article}
\usepackage{amsmath,amssymb}
\pagestyle{empty}
\begin{document}

The quantity we care about is
\[
E = \frac{x_i^2}{\sqrt{y}}
\]
and its partial sums converge,
\[
\sum_{k=1}^{n} \frac{1}{k^2} = \frac{\pi^2}{6} - \varepsilon_n .
\]
For a linear map we write
\[
A = \begin{pmatrix} a & b \\ c & d \end{pmatrix},
\qquad
\det A = ad - bc .
\]

This sentence contains $\sqrt{a^2+b^2}$ inline, which \texttt{--inline}
finds. It also names the vector $\mathbf{v}$, which nothing can find:
\verb|\mathbf| and bold prose are the same font.

\end{document}
